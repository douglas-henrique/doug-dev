# Personal software

[Douglas Pereira](/en)

## It does not have to scale

- One user is a valid market
- Hardcoded is a feature when the user is you
- Stop when it works on your machine for real

## Small on purpose

- A weekend tool beats an abandoned platform
- No accounts, unless you enjoy suffering
- Delete the roadmap

## Follow the itch

- Automate the thing you did three times
- Ugly UI is allowed
- Ship to yourself on Friday

## This is how you keep taste

- Side projects are gym, not a second job
- Play with the new toy here, not in production
- Fun is a serious reason
