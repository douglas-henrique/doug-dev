# Experiência de desenvolvimento

[Douglas Pereira](/pt)

## O caminho feliz precisa ser óbvio

- Setup em um comando, ou você já perdeu gente
- Erro tem que dizer o que fazer depois
- Se sênior ainda precisa de wiki para subir o app, o app é o problema

## Velocidade é respeito

- Teste lento é teste pulado
- Deploy lento vira lote de risco
- Feedback rápido é como o gosto se forma

## Docs são o produto

- README é a porta da frente
- Se você respondeu a pergunta duas vezes, escreve
- Exemplo ganha de adjetivo

## Tira passo

- Cada flag extra é uma chance de desistir
- Default tem que parecer com o jeito que as pessoas trabalham
- A melhor DX é a que você para de notar
