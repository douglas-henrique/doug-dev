# Engenheiros de produto

## Dono do resultado

- O ticket é um palpite
- Fala com quem sente a dor
- Mede alguma coisa, mesmo que seja tosco

## Design não é handoff

- Senta no estado vazio
- Texto faz parte da interface
- Se é estranho de usar, não está pronto

## Full stack é direção

- Backend o bastante para entregar a feature
- Frontend o bastante para não se esconder atrás de "isso é design"
- Pede ajuda sem jogar o problema por cima do muro

## Gosto é o diferencial

- Muita gente faz funcionar
- Pouca gente faz ficar óbvio
- Esse é o trabalho agora
