# Software pessoal

[Douglas Pereira](/pt)

## Não precisa escalar

- Um usuário é mercado válido
- Hardcoded é feature quando o usuário é você
- Para quando funcionar de verdade na sua máquina

## Pequeno de propósito

- Ferramenta de fim de semana ganha de plataforma abandonada
- Sem conta, a não ser que você goste de sofrer
- Apaga o roadmap

- Automatiza o que você fez três vezes
- UI feia é permitida
- Entrega para você na sexta

## É assim que o gosto se mantém

- Side project é academia, não segundo emprego
- Brinca com o brinquedo novo aqui, não em produção
- Diversão é motivo sério
