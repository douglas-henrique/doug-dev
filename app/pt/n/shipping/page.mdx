# Entregar

[Douglas Pereira](/pt)

## Faz pousar

- Branch não é produto
- Atrás de flag ainda conta
- Atrás de reunião não conta

## Encolhe a primeira versão

- Se precisa de lançamento, provavelmente está grande
- Corta escopo até dar uma vergonha leve
- Aí entrega e escuta

## O ciclo é a estratégia

- Constrói, mostra, muda de ideia
- Status não é feedback
- O cliente te conta o ticket de verdade

## Momentum acumula

- Time que entrega aprende mais rápido
- Time que espera fica bom em esperar
- Faz o próximo ship menor do que a última desculpa
